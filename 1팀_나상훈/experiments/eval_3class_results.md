# 3클래스(부정/중립/긍정) 모델 결과 (prepare_3class.py → train_3class.py → eval_3class.py)

## 데이터 (NSMC 원본 raw/, 평점 1~10)
- 원본 712,383개 리뷰, 14,730편 → 중복·라벨 모순(같은 문장이 다른 클래스) 제거 후 686,645개
- 라벨: 1~4 부정, **5~8 중립**(NSMC가 제외한 구간), 9~10 긍정
- **영화 단위** 8:1:1 분리 (같은 영화가 train/test에 같이 있지 않음), val/test 문장이 train에 없음을 assert로 확인
- 클래스 균형: train 50,000 × 3, val 3,000 × 3, test 3,000 × 3

## 학습 (RTX 3080, conda part4: Python 3.10, torch 2.14.1+cu126, transformers 5.20.2)
- 시작: `monologg/koelectra-small-v3-discriminator` (감성 학습 전 모델 → NSMC 학습 리뷰가 test에 섞일 위험 없음)
- AdamW lr 1e-4, batch 64, 3 epoch, warmup 6% + 선형 감소, fp16 혼합 정밀도, grad clip 1.0, seed 42
- epoch당 약 170초

| epoch | train loss | val 정확도 | val macro-F1 |
|---|---|---|---|
| 1 | 0.7892 | 68.17% | 0.6804 |
| 2 | 0.6614 | 69.84% | 0.6970 |
| 3 | 0.5985 | 70.21% | **0.7018** ← 저장 |

## test 9,000개: A vs B
- A = 서비스 중인 2클래스 모델(INT8, T=2.30) + 긍정 확률이 0.10~0.88이면 중립 (구간은 val에서 macro-F1 최대로 선택)
- B = 새로 학습한 3클래스 모델 (PyTorch FP32)

| | 정확도 | 부정 F1 | **중립 F1** | 긍정 F1 | macro-F1 |
|---|---|---|---|---|---|
| A. 2클래스 + 애매하면 중립 | 62.40% | 0.759 | 0.376 | 0.692 | 0.609 |
| **B. 3클래스 학습** | **70.22%** | 0.758 | **0.617** | 0.729 | **0.702** |

중립: 정밀도 0.447→0.632, 재현율 0.324→0.603

## 애매한 문장
| 문장 | A: 긍정 확률 → 판정 | B: 부정 / 중립 / 긍정 → 판정 |
|---|---|---|
| 배우는 좋은데 스토리가 별로 | 0.08 → 부정 | 0.41 / 0.58 / 0.00 → **중립** |
| 스토리는 별로인데 배우는 좋다 | 0.12 → 중립 | 0.18 / 0.79 / 0.03 → 중립 |
| 그냥 그랬어요 | 0.04 → 부정 | 0.21 / 0.78 / 0.01 → **중립** |

| 나쁘지 않았어요 | 0.93 → 긍정 | 0.01 / 0.90 / 0.09 → **중립** |
| 좋지도 나쁘지도 않은 영화 | 0.94 → 긍정 | 0.03 / 0.91 / 0.05 → **중립** |
| 기대보다는 별로였지만 볼만했어요 | 0.94 → 긍정 | 0.01 / 0.91 / 0.08 → **중립** |
| 한번쯤 볼만한 킬링타임용 | 0.13 → 중립 | 0.03 / 0.94 / 0.03 → 중립 |

## 해석
- 재학습 없이 확률 구간으로 중립을 만드는 A는 중립 F1 0.376으로 한계가 분명함 → 중립은 **학습해야** 구분 가능.
- B의 정확도 70%는 2클래스 89%보다 낮지만 **문제가 다름**(3지선다, 그리고 2클래스는 가장 쉬운 양 끝 평점만 사용). 같은 3클래스 test에서 A보다 7.8%p 높음.
- 정답 라벨이 "작성자가 준 별점"이라 본질적으로 시끄러움: 8점 리뷰 상당수는 글만 보면 칭찬. B가 8점의 38%를 긍정으로 본 것은 오답이지만 사람이 읽어도 그렇게 판단할 만한 경우가 많을 것으로 보임(추측, 직접 라벨링해 확인하지 않음).
