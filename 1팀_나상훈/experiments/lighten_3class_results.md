# 3클래스 모델 경량화·보정 결과 (lighten_3class.py, 원문: lighten_3class_results.txt)

환경: Windows 11, Ryzen 5 5600, Python 3.14.6, torch 2.13.0+cpu, onnxruntime 1.31.1, 스레드 4. test 9,000개(클래스당 3,000), 리뷰 1개씩(bs=1).
전처리 확인: 서버용 `tokenizers`(tokenizer.json) ↔ transformers 토큰 불일치 **0 / 9,000**. ONNX 변환 확인: PyTorch↔ONNX FP32 logit 최대 차이 1.87e-05.

| PyTorch FP32 | 53.9 | 70.24% | 0.7018 | - | 0 | 10.23 |

→ 크기 3.9배↓, PyTorch FP32 대비 4.6배 빠름, 정확도 차이(0.2%p)는 통계적으로 유의하지 않음.
(McNemar p값은 처음 1.00으로 출력됐으나 numpy 정수 오버플로 버그였음 → 수정 후 scipy `binomtest`와 같은 0.229 확인, debugging_log #10)
